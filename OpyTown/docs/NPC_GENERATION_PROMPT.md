# Supervisor NPC Generation Prompt

## Image Specifications

**Display Size in Game:** 100×120 pixels (width × height)  
**Recommended Source Image Size:** 200×240 pixels (for pixel art quality) or 250×300 pixels (higher detail)

**Aspect Ratio:** ~1.2:1 (slightly taller than wide, similar to player model)

---

## Text Prompt for Image Generation

```
Create a pixel art character sprite for a coffee buyer/supervisor NPC in a top-down 2D game. 

Character Description:
- Professional coffee buyer/supervisor character
- Business-casual attire appropriate for a coffee trading setting
- Friendly but professional appearance
- Standing pose, facing forward (front view)
- Can be holding a clipboard, tablet, or coffee sample
- Distinctive appearance that suggests authority/coordination role

Art Style:
- Pixel art style, 8-bit to 16-bit aesthetic
- Top-down/isometric perspective (viewed from above at slight angle)
- Colorful but cohesive color palette
- Clear silhouette and readable details
- Consistent with coffee/trading theme

Technical Requirements:
- Static image (no animation needed)
- Transparent background (PNG format)
- Size: 200×240 pixels (or 250×300 for higher detail)
- Character should be centered in the image
- Clear, readable features at small scale (100×120 display size)

Visual Elements to Include:
- Professional clothing (could include: button-up shirt, vest, or business casual outfit)
- Coffee-related accessories (clipboard with order forms, coffee bean sample, or tablet)
- Distinctive hat or hairstyle to make character recognizable
- Warm, approachable color scheme (browns, tans, warm earth tones with accent colors)
- Clear facial features (even if simplified for pixel art)

Reference Context:
- This character represents a "Coffee Buyer" who coordinates coffee purchases from multiple farms
- They are the main interactable NPC in a coffee trading game
- Should look trustworthy and professional, like someone who manages coffee supply chains
```

---

## Alternative Shorter Prompt

```
Pixel art character sprite: Coffee Buyer Supervisor NPC, professional business-casual attire, holding clipboard or coffee sample, friendly professional appearance, top-down view, 200×240 pixels, pixel art style, transparent background, static image, warm earth tone color palette, clear readable features.
```

---

## Size Comparison

- **Player Model:** 100×70 pixels (display size)
- **Supervisor NPC:** 100×120 pixels (display size) - slightly taller to show authority
- **Source Image:** 200×240 pixels recommended (2x scale for pixel art quality)

---

## Notes

- The NPC will be displayed at 100×120 pixels in the game
- Source image should be 2x-2.5x larger for best pixel art quality
- Only one static pose is needed (facing forward)
- The character will have a name tag rendered above them in-game
- Farm labels (Brazil, Colombia, Vietnam) are rendered as text on the background, not as separate NPCs
